# Ferramentas de prototipação

Referências consultadas em 2026-09-23. Recursos, acesso e permissões podem mudar; verifique a documentação e as ferramentas expostas na sessão antes de prometer uma operação.

| Caminho | Quando ajuda | Verificação necessária | Alternativa sem conexão |
|---|---|---|---|
| Código local no Claude Code | Avaliar uma interação navegável | Pasta autorizada, ambiente e forma de abrir/testar | Entregar arquivos e instruções de abertura; informar testes pendentes |
| Google Stitch | Explorar interfaces a partir de um briefing | Recursos disponíveis no serviço e acesso do usuário | Briefing para inserir manualmente no Stitch |
| Figma por MCP | Trabalhar com contexto de design ou canvas | Servidor conectado, ferramentas disponíveis, arquivo e permissões | Briefing, mapa de telas ou protótipo local conforme o pedido |

O Google apresenta Stitch como ferramenta para gerar interfaces e código de frontend a partir de texto e imagens. Este pacote fornece orientação de uso; não distribui um servidor MCP do Stitch nem garante uma integração instalada.

O servidor MCP do Figma documenta capacidades de leitura e escrita. Não deduza as capacidades da sessão pelo nome da conexão: confirme a operação disponível antes de criar ou alterar conteúdo. Use os fluxos oficiais associados à ferramenta escolhida.

Um briefing deve trazer a tarefa do usuário, regras e estados que precisam aparecer. Solicite material visual ou design system apenas quando isso mudar a entrega. Evite transmitir dados reais de clientes para ferramentas externas sem autorização pertinente.
