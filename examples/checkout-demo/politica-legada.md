# Política legada de checkout — documento fictício

Material criado para exercitar identificação de divergências. Não é política de uma empresa.

- Cupom não acumula com oferta individual superior a 15%.
- O desconto de cupom é limitado a R$ 100,00.
- Para Sudeste, frete grátis em compras acima de R$ 150,00.
- Para demais regiões, frete grátis em compras acima de R$ 299,00.
- O cupom BEMVINDO deveria expirar 30 dias após cadastro.

Este documento pode estar desatualizado. A demonstração não estabelece qual regra deve prevalecer.
