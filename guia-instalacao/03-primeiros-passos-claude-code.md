# Primeiros passos com Claude Code

Depois de instalar a ferramenta, abra o terminal na pasta em que você guardou seus materiais e execute `claude`. Siga a autenticação apresentada pela ferramenta; condições de acesso podem mudar e devem ser conferidas na documentação oficial.

Você pode trabalhar com uma pasta de iniciativas, requisitos e briefings. Não precisa começar com um repositório de código. Use materiais que tenha autorização para analisar.

## Comece por uma tarefa pequena

Após [instalar a skill](04-instalar-a-skill.md), experimente:

> Use product-prioritization. Leia iniciativas.md e me ajude a comparar estas propostas para o próximo trimestre. Se faltar informação, mostre a lacuna. Quero a resposta nesta conversa.

Ou:

> Use product-prototyping. Leia briefing.md e prepare um roteiro de telas para testar esta hipótese. Nesta etapa quero apenas o briefing, sem criar arquivos no Figma.

Informe a decisão, os materiais, o escopo e a saída desejada. A skill deve aproveitar esses dados sem repetir as mesmas perguntas.

## Confira o resultado

Verifique se a resposta cita a origem dos dados, separa premissas de fatos e declara limitações. Um score não aprova uma prioridade; um protótipo não valida a hipótese com usuários.

Claude Code pode executar ações no ambiente conforme ferramentas e permissões. Configure as permissões adequadas ao trabalho. O texto de uma skill não implementa isolamento nem substitui controles da ferramenta.

Use `/help` para os comandos disponíveis. Consulte [a documentação de Claude Code](https://code.claude.com/docs/en/overview) e [o guia de skills](https://code.claude.com/docs/en/skills) para configuração atual.
